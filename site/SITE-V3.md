# Сайт vsemkod.ru v3: настоящая копия харнесса в браузере

Владелец сказал прямо: в первом экране должна быть **буквально копия нашего приложения vsemkod**, которая полностью прокликивается и почти полностью работает. Никаких декоративных фонов и «окна приложения на картинке». Текущий `site/` (v2) — основа: темы, шрифты, протокол демо-API, Turnstile, каталог — оставляем, раскладку секций переделываем.

Бренд и запреты — как в `site/SITE-V2.md`: графит `#0F1112` + мятный `#3DDC97`, без эмодзи и «нейрослопа», весь текст по-русски, ничего не копировать с чужих сайтов. Тёмная тема по умолчанию всегда, светлая — по переключателю.

## A. Веб-копия харнесса из настоящего кода приложения
Не верстать копию заново. **Собрать настоящий renderer приложения (`app/src/renderer`) для браузера** с веб-реализацией API, которое в Electron даёт preload (`DesktopApi` из `app/src/shared/api.ts`).
- `app/src/web/` — точка входа `main.tsx` (ставит веб-API в то же место, где renderer ждёт preload-API, и рендерит то же приложение) и `demo-api.ts` (реализация `DesktopApi`). Отдельный конфиг сборки `app/vite.web.config.ts`, скрипт `npm run build:web` → папка `site/harness/` (в `.gitignore`; на GitHub Pages собирается в CI, см. раздел D). Никаких Node/Electron API в веб-бандле, бюджет JS ≤ 250 КБ gzip.
- Поведение веб-API:
  - **Модели**: каталог из `/catalog.json` (тот же сайт). Выбрать можно только демо-модель (имя из `GET {DEMO_API}/status`, подпись «бесплатно в браузере»). Остальные модели каталога видны как в приложении, но неактивны с пометкой «в приложении»; «Подключить» и любые входы/ключи → аккуратный диалог «Это доступно в приложении» с кнопкой «Скачать».
  - **Чаты**: в памяти вкладки. «Новый чат» работает, список чатов в боковой панели, проект «Демо-проект». Перезагрузка — всё пусто. В заголовке окна чип «Чаты не сохраняются».
  - **Отправка**: через демо-API по протоколу из `site/SITE-V2.md` (Turnstile, сессия, SSE) — ответ стримится в обычный вид сообщений приложения (markdown, код с «Копировать»). Лимиты и закрытие демо — тостами приложения и карточкой «Скачать».
  - **Настройки**: открываются все разделы с настоящей раскладкой, но элементы управления неактивны; сверху плашка «Демо в браузере: настройки работают в приложении · Скачать». Переключатель темы — работает и синхронизирован с темой сайта (`postMessage` с родителем, `localStorage` `vsemkod-theme`).
  - **Остальное** (вложения, @-файлы, /команды, правая панель): интерфейс открывается; файлы и дерево — небольшой фиктивный «демо-проект» (3–5 файлов, только чтение); терминал и действия с диском — подсказка «Работает в приложении».
  - **Кнопка «Скачать»** — заметная, в заголовке окна копии; ведёт на страницу загрузки/релиз (та же логика ОС, что в `site/app.js`).
- **Режим сценариев** `?scenario=<id>`: без ввода, в цикле проигрывает сценарии через тот же поток событий, что и живой чат (движок не нужен — заскриптованные события): `edit` (агент читает и правит файлы, дифф, «Готово»), `revert` (откат к сообщению), `modes` (режим «Только чтение» → план → «Выполнить план»), `failover` (тост «Переключился на GLM 5.3 — у Kimi кончилась квота»), `subscriptions` (меню моделей с группами, подключение подписки), `mcp` (настройки MCP и навыки), `todo` (список задач агента + вопрос агента). Переключение сценария снаружи — `postMessage({ type: "vsemkod:scenario", id })`. Сценарии — данные, их легко менять.
- Проверь, что копия в браузере выглядит **один в один** как Electron-приложение (сравни со скриншотами `app/screenshots/`), в обеих темах.

## B. Секции сайта (сверху вниз)
1. **Первый экран**: заголовок «Бесплатный AI‑кодинг для всех», короткий подзаголовок, кнопка «Скачать для <ОС>» + «Все загрузки». Сразу под ними — **копия харнесса** (`<iframe src="/harness/">` без рамок-декораций, как настоящее окно: скругление, тонкая граница, мягкая тень), ширина контента до ~1240px, высота `min(780px, 82vh)`. На мобильных — адаптивная раскладка самого приложения (боковая панель сворачивается). Никакого фона-сцены с кривыми.
2. **«Бесплатно прямо сейчас»** — слайдер во всю ширину экрана: две ленты карточек моделей, бесконечно и плавно едут в разные стороны (CSS-анимация, пауза при наведении). Карточка: качественный **SVG-логотип производителя** (Kimi/Moonshot, DeepSeek, Z.ai/GLM, Qwen, MiniMax, Xiaomi MiMo, NVIDIA Nemotron, OpenAI gpt-oss, Google Gemma и т.д.), имя модели, у кого бесплатно. Данные — из каталога (top + good; для `new` — карточка «+N новых»). Логотипы — из MIT-набора `@lobehub/icons-static-svg` (npm), скопируй только нужные SVG в `site/assets/logos/`, добавь `site/THIRD_PARTY.md` с лицензией. При `prefers-reduced-motion` — статичная сетка.
3. **«Скачай и работай — как в Claude Code, только бесплатно»** — 4 шага с картинками: (1) **Скачай** — настоящая интерактивная кнопка загрузки (определение ОС, анимация нажатия и «загрузки», затем переход на файл/релиз); (2) **Выбери папку**; (3) **Напиши задачу**; (4) **Работай** — агент правит код. Для шагов 2–4 сделай скриншоты **из веб-копии харнесса** (headless Chrome, сценарии), сохрани в `site/assets/steps/*.webp` (обе темы, выбирается по теме сайта).
4. **«Возможности»** — motion: секция со «скроллителлингом». Слева 6 пунктов (заголовок + 1 строка): агент правит файлы и показывает диффы; откат одним кликом; режимы доступа и план; модель меняется сама, когда кончилась квота; свои подписки и ключи; MCP, навыки и правила. Справа — **липкая живая копия харнесса** (iframe в режиме сценариев); при прокрутке активный пункт подсвечивается, у него полоска прогресса, копия переключается на его сценарий (`postMessage`). На мобильных — пункты по очереди, под каждым копия со своим сценарием (лениво, только видимая).
5. **«Наша цель»** — манифест крупным текстом, слова «проявляются» по мере прокрутки (opacity от 0.2 до 1, scroll-linked). Текст (можно слегка отполировать, смысл не менять):
   > Мы хотим дать всему миру возможность кодить бесплатно.
   > Мы устали смотреть, как людей разводят на деньги — продают курсы, подписки и «секретные промпты». Нейросети уже умеют писать код, а лучшие из них регулярно раздают бесплатно.
   > Наш бот сам находит такие раздачи каждые 30 минут. От вас ничего не требуется: скачали — и работаете. Весь код открыт — проверяйте, улучшайте, делайте своё.
   Под текстом: «Смотреть код на GitHub», время последнего обновления каталога.
6. **FAQ** (как сейчас, плюс вопрос про демо-чат и что ничего не сохраняется), подвал.

## C. Анимации
Появление секций, лент и шагов — мягко (opacity/transform, 400–700 мс), никаких «прыжков» макета. Всё уважает `prefers-reduced-motion`. Lighthouse десктоп: производительность и доступность ≥ 90 (iframe первого экрана грузится сразу, остальные — лениво).

## D. Сборка и публикация
- `site/app.js`: `DEMO_API = "https://vsemkod-demo.vsemkod.workers.dev"`, `TURNSTILE_SITEKEY` уже задан. Веб-копия берёт их из общего конфига (например `site/config.js`, подключаемого и сайтом, и копией), без дублирования.
- `.github/workflows/pages.yml`: перед сборкой `_site` — Node 24, `npm ci` в `app/` (без скачивания Electron и движка: `ELECTRON_SKIP_BINARY_DOWNLOAD=1` и т.п.), `npm run build:web` → `_site/harness/`. Триггеры дополнить путями `app/src/**`, `app/package*.json`, `app/vite.web.config.ts`.
- Локальный мок `site/dev/mock-demo-api.mjs` продолжает работать (для копии тоже).
