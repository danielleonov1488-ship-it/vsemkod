# Лендинг vsemkod.ru

Статический сайт на GitHub Pages. Для публикации достаточно HTML, CSS и ES-модулей. Каталог и журнал изменений попадают в корень сайта из `catalog-bot/data/` при сборке Pages.

- `index.html` и `styles.css` задают первый экран, две ленты моделей, четыре шага, возможности, манифест и FAQ. Тёмная тема включена при первом визите. Настройка хранится в `localStorage` под ключом `vsemkod-theme`.
- `app.js` загружает активные раздачи для моделей `top` и `good`, считает новые модели с активными предложениями и берёт дату обновления из каталога. Ленты можно остановить кнопкой. При `prefers-reduced-motion` модели показаны статичной сеткой.
- `assets/d-*.webp` и `assets/steps/*.webp` подготовлены из скриншотов `app/screenshots/d-*.png` в обеих темах. Происхождение и лицензия логотипов указаны в [THIRD_PARTY.md](THIRD_PARTY.md).
- Ссылки скачивания открывают актуальный релиз GitHub, основная кнопка определяет ОС, а кнопка в первом шаге показывает короткую анимацию перехода.

## Встраивание приложения

Главная страница проверяет доступность `/harness/` и сразу загружает демо при наличии сборки. До загрузки показывает снимок приложения. Десктопные возможности используют один липкий iframe, мобильные монтируют iframe видимого сценария. Начальный сценарий передаётся в URL `/harness/?scenario=<id>`.

- `{ type: "vsemkod:scenario", id }` переключает сценарий в iframe. Лендинг использует `edit`, `revert`, `modes`, `failover`, `subscriptions` и `mcp`.
- `{ type: "vsemkod:theme", theme: "dark" | "light" }` синхронизирует тему в обе стороны. Лендинг отправляет сообщения только на свой origin и принимает их от своих iframe.
- После загрузки iframe лендинг передаёт тему и текущий сценарий. Сообщение `{ type: "vsemkod:ready" }` из iframe запрашивает повторную отправку.

Константы `DEMO_API` и `TURNSTILE_SITEKEY` находятся в `app.js`. Протокол демо-API описан в [SITE-V2.md](SITE-V2.md).

## Локальная проверка

Из корня репозитория запусти `node site/dev/mock-demo-api.mjs --static` и открой `http://127.0.0.1:4173`. Сервер читает снимок каталога из репозитория и отдаёт `/harness/`, когда собран `site/harness/index.html`.

Без `--static` сервер подставляет локальный `/demo` и публичный тестовый ключ Turnstile в `app.js`. `MOCK_PORT`, `MOCK_REMAINING` и `MOCK_CLOSED=1` задают порт, лимит сессии и исчерпанную дневную квоту.

Скриншоты проверки в Chrome сохранены в `dev/screenshots/v3/`. Папка `dev/` исключена из публикации.
