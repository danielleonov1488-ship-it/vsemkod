# Бриф: лендинг vsemkod.ru

Рабочая папка — `site/` внутри репозитория `vsemkod`. Ассеты уже лежат в `site/assets/` (скриншоты приложения `app-models.png`, `app-home.png`, логотип `logo.svg`, картинки для превью ссылок `og-image.png`, `og-avatar.png`). Бренд-гайд — макеты в стиле приложения: графит `#0F1112`, панели `#17191B`, текст `#E8EAEB` / вторичный `#9BA1A6`, акцент мятный `#3DDC97` (точечно). Вордмарк: «vsem» светлым + «kod» мятным, рядом бегемотик `logo.svg`.

## Что сделать
Одностраничный статичный лендинг: **чистые HTML + CSS + немного ванильного JS**, без фреймворков и сборщиков, без внешних шрифтов/CDN/трекеров/аналитики (системные шрифты: `"Segoe UI Variable", "Segoe UI", Inter, system-ui, -apple-system, Roboto, sans-serif`). Файлы: `site/index.html`, `site/styles.css`, `site/app.js`, `site/404.html`, `site/favicon.svg` (бегемотик), `site/robots.txt`.

Уровень дизайна — как сайты Linear / Raycast / Zed: спокойно, дорого, много воздуха, без «нейрослопа» (никаких эмодзи в интерфейсе, неоновых свечений, карточек в карточках, звёздочек-рейтингов). Тёмная тема. Адаптив: телефон 375px, планшет, десктоп 1440px.

### Блоки (по порядку)
1. **Шапка**: логотип-вордмарк слева; справа ссылки «Модели», «Как это работает», «FAQ», «GitHub» (https://github.com/danielleonov1488-ship-it/vsemkod) и кнопка «Скачать».
2. **Hero**: заголовок «Бесплатный AI‑кодинг для всех», подзаголовок «Топовые нейронки, которые прямо сейчас раздают бесплатно, — в одном приложении. Выбрал папку, написал задачу — агент сам пишет код.», кнопки «Скачать для Windows» (основная, мятная; определяй ОС по userAgent и подставляй macOS / Linux) и «Исходный код на GitHub» (вторичная). Под кнопками мелко: «Бесплатно и с открытым кодом · Windows, macOS, Linux». Ниже — большой скриншот `assets/app-models.png` в аккуратной рамке окна (скругление, тонкая граница, мягкая тень).
   - Пока нет релиза: кнопка скачивания ведёт на https://github.com/danielleonov1488-ship-it/vsemkod/releases/latest , а рядом маленькая плашка «Скоро первая версия». Вынеси URL релизов и флаг `RELEASED=false` в начало `app.js`, чтобы потом поменять одной строкой.
3. **«Бесплатно прямо сейчас»** (`id="models"`): живой список моделей из каталога. `app.js` загружает `/catalog.json` (тот же домен), при ошибке — запасной URL `https://raw.githubusercontent.com/danielleonov1488-ship-it/vsemkod/main/catalog-bot/data/catalog.json`. Показывай только `offers` со `status === "active"` для моделей `tier === "top"` (группируй по модели): название модели, короткое описание (`models[].description`), чипы провайдеров (`providers[].name`), пометка «акция до DD.MM», если есть `expiresAt`. Внизу строка «Каталог обновлён N мин назад · обновляется каждые 30 минут» (из `generatedAt`). Пока грузится — аккуратный скелетон; если всё упало — текст «Не удалось загрузить каталог» + ссылка на JSON. Сделай рендер безопасным (никакого innerHTML с данными — textContent/DOM API).
4. **«Как это работает»** (`id="how"`): три шага — «Скачай и открой» (выбери папку проекта или оставь папку по умолчанию), «Подключи модели в один клик» (вход через Google/GitHub у провайдера, без подписок и API‑ключей), «Пиши задачу» (агент читает проект, пишет код, запускает; если модель упёрлась в лимит — vsemkod сам переключится на другую). Можно со вторым скриншотом `assets/app-home.png`.
5. **Преимущества** (4 пункта, сетка 2×2, тихо, без карточек-«плиток»): «Только топовые модели» · «Каталог обновляется сам» · «Ключи и чаты — только на твоём компьютере» · «Открытый код (MIT)».
6. **FAQ** (`id="faq"`, `<details>`): «Это правда бесплатно?» (да: модели раздают сами провайдеры, приложение работает на твоих бесплатных квотах, мы ничего не продаём), «Откуда бесплатные модели?» (бот круглосуточно собирает раздачи у OpenRouter, Kilo, Numes, Runcrate, Z.ai и других), «Где хранятся мои ключи и код?» (только на твоём компьютере; запросы идут напрямую к провайдеру; бесплатные провайдеры могут логировать запросы — не отправляй секреты), «Что будет, когда раздача закончится?» (каталог обновится, приложение переключится на другую бесплатную модель), «Нужна ли регистрация в vsemkod?» (нет, аккаунта у нас нет).
7. **Футер**: вордмарк, «© 2026 vsemkod · MIT», ссылки GitHub, «Каталог моделей (JSON)» → `/catalog.json`.

## Деплой (GitHub Pages через Actions)
Создай `.github/workflows/pages.yml` в КОРНЕ репозитория (`../.github/workflows/pages.yml` относительно site/):
- триггеры: `push` в `main` (пути `site/**`, `catalog-bot/data/catalog.json`, сам workflow), `workflow_run` после завершения workflow «Update catalog» (успешного), `workflow_dispatch`;
- job build: checkout → собрать папку `_site`: скопировать `site/*` (кроме `BRIEF.md`), скопировать `catalog-bot/data/catalog.json` и `changes.json` в корень `_site`, создать `_site/CNAME` с `vsemkod.ru`, `.nojekyll` → `actions/upload-pages-artifact`;
- job deploy: `actions/deploy-pages`, permissions `pages: write`, `id-token: write`, environment `github-pages`, concurrency `pages`.
- Используй актуальные мажорные версии действий (проверь теги на GitHub, например `actions/checkout@v7`; для pages-действий выясни актуальные мажоры через `git ls-remote --tags`).

## Проверка
- Открой страницу локально: подними простой статический сервер из корня собранного `_site` (например `npx --yes serve` не используй — без установки; используй `python -m http.server` из собранной папки) и сними скриншоты Chrome headless в 1440×900 и 390×844 (`--window-size`), посмотри их через view_image и исправь всё кривое (2 круга). Убедись, что список моделей реально рендерится из `catalog.json`.
- В конце перечисли файлы и что проверено.

## Ограничения
Работай только внутри репозитория `vsemkod` (папки `site/` и `.github/workflows/`). Не коммить, не пушь, ничего не устанавливай глобально.
