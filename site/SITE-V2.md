# Сайт vsemkod.ru v2: живая демо-панель, тёмная и светлая темы, анимации

Переделываем `site/` (статический сайт на GitHub Pages: HTML, CSS, ванильный JS, без сборки и фреймворков). Уровень полировки — как у лучших продуктовых лендингов агентных IDE (спокойная типографика, много воздуха, крупный живой макет продукта в первом экране, мягкие анимации). Свой код и свои тексты: **ничего не копировать с чужих сайтов** (ни код, ни картинки, ни формулировки).

Бренд: графит `#0F1112` + мятный `#3DDC97`, логотип `assets/logo.svg`, словесный знак «vsem» светлым + «kod» мятным. Без эмодзи, без «нейрослопа» (никаких градиентных блобов, стеклянных карточек с тенями, иконок-кружочков с подписями «Быстро / Удобно / Надёжно»). Весь текст по-русски, коротко и по делу. Шрифт системный (`Segoe UI Variable`, `Inter`, system-ui), моно для кода (`ui-monospace, "Cascadia Code", Menlo, monospace`).

## 1. Темы
- **Тёмная по умолчанию**, светлая — по переключателю (иконка солнце/луна в шапке) и по `prefers-color-scheme: light` при первом визите. Выбор хранится в `localStorage` (`vsemkod-theme`), без мигания при загрузке (маленький inline-скрипт в `<head>`).
- Все цвета — CSS-переменные в `:root[data-theme="dark"]` / `:root[data-theme="light"]`.
  - Тёмная: фон `#0F1112`, поверхность `#16191B`, приподнятая `#1C2023`, линия `#262B2E`, текст `#E8ECEA`, вторичный `#9BA3A0`, акцент `#3DDC97`, текст на акценте `#06281A`.
  - Светлая (тёплая, не стерильно-белая): фон `#F5F4F0`, поверхность `#FFFFFF`, приподнятая `#FBFAF7`, линия `#E4E1DA`, текст `#141617`, вторичный `#5E6461`, акцент для текста и кнопок `#0F8F5A` (контраст AA), мятный `#3DDC97` — только для декоративных линий.
- Проверь контраст текста AA в обеих темах.

## 2. Шапка
Липкая, на прокрутке — фон с лёгким `backdrop-filter: blur` и тонкой нижней линией. Слева логотип + словесный знак. В центре/справа ссылки: «Модели», «Как это работает», «Возможности», «FAQ», «GitHub». Справа переключатель темы и кнопка «Скачать» (пилюля). На мобильных — меню-бургер.

## 3. Первый экран (hero)
- Сетка в две колонки: слева крупный заголовок «Бесплатный AI‑кодинг для всех» (clamp ~40–64px, плотный межстрочный), справа, выровненный по нижнему краю заголовка, подзаголовок в 2 строки: «Агент пишет код в твоей папке на лучших бесплатных моделях. Без подписок, без карты». Под заголовком две пилюли: «Скачать для Windows» (определяется ОС, логика уже есть в `app.js`) и «Все загрузки →». Сверху маленький чип-анонс (из каталога: «Новая раздача: <модель> бесплатно» — самое свежее событие top-модели из `changes.json`, иначе «Открытый код · MIT»).
- Ниже — широкая **сцена** во всю ширину контента: поверхность с крупными закруглениями, на фоне медленно плывущие мятные кривые (2–4 SVG-пути с толстым штрихом разной прозрачности, анимация `stroke-dashoffset`/`transform` 20–40 с, бесконечно; в светлой теме — мягкий мятный фон сцены). Поверх — **окно приложения vsemkod, свёрстанное HTML/CSS** (не картинка), визуально как наше приложение (`app/design/png/*.png`, `app/design/free-ai.css` — возьми оттуда токены и раскладку): заголовок окна с кнопками, боковая панель (Новый чат, список из 3 чатов, Настройки), область чата, поле ввода снизу с чипом папки и селектором модели.

## 4. Живая демо-панель (это главное)
Окно в сцене — настоящий чат.
- **Автопроигрывание**, пока пользователь не трогает: сценарий работы агента в цикле (пользователь просит «Добавь тёмную тему в настройки», агент: «Прочитал settings.tsx» → «Изменил settings.tsx +24 −3» с раскрывающимся мини-диффом → «Запустил npm test — 17 пройдено» → короткий итог). Печать текста посимвольно, строки действий появляются по очереди, плавные переходы. Сценарий — данные в JS, легко менять.
- **Как только пользователь кликает в поле ввода**, автопроигрывание останавливается, чат очищается, плейсхолдер «Спроси что угодно — бесплатно, без регистрации». Сообщения уходят в демо-API (протокол ниже), ответ стримится посимвольно с markdown (заголовки, списки, `inline code`, блоки кода с подсветкой фона и кнопкой «Копировать» — простой свой мини-рендер, без внешних библиотек; HTML из ответа экранировать, XSS невозможен).
- В селекторе модели — модель демо (имя из `GET /status`), плюс неактивные пункты топ-моделей из каталога с подписью «в приложении».
- **Чат «сгорает»**: история только в памяти страницы (не `localStorage`, не cookies). Чип в шапке окна «Не сохраняется · сгорит через 10:00» — таймер от последнего сообщения; по истечении или по кнопке «Сжечь» — сообщения красиво растворяются (fade + лёгкое размытие/сдвиг), чат пуст. Перезагрузка страницы — тоже пусто.
- Лимиты показываем честно: «Осталось N сообщений» (из ответа API). Когда лимит/квота исчерпаны или API недоступен — в окне карточка «Демо на сегодня закончилось. В приложении — без лимитов сайта, с файлами и командами» + кнопка «Скачать».
- Если демо-API не настроен (`DEMO_API = ""` в начале `app.js`) — только автопроигрывание, поле ввода показывает «Живой чат скоро — а пока скачай приложение».
- Защита от ботов: невидимый виджет Cloudflare Turnstile (sitekey — константа `TURNSTILE_SITEKEY` в `app.js`, скрипт `https://challenges.cloudflare.com/turnstile/v0/api.js` подключать лениво, только при первом фокусе на поле ввода). Токен Turnstile отправляется в `POST /session`.
- Ограничения ввода на клиенте: до 2000 символов в сообщении, Enter — отправить, Shift+Enter — перенос, кнопка «Стоп» во время ответа (abort fetch).

### Протокол демо-API (`DEMO_API` — базовый URL воркера)
- `GET /status` → `{ "open": true, "model": { "id": "...", "name": "..." } }` (`open: false`, когда дневная квота исчерпана).
- `POST /session` тело `{ "turnstile": "<token>" }` → `{ "token": "...", "expiresAt": 1730000000000, "remaining": 10 }`. Ошибки — JSON `{ "error": { "code": "...", "message": "..." } }` с HTTP-статусом.
- `POST /chat` заголовок `Authorization: Bearer <token>`, тело `{ "messages": [{ "role": "user"|"assistant", "content": "..." }] }` (клиент шлёт только последние 8 сообщений) → `text/event-stream`, строки `data: {...}`:
  - `{ "t": "delta", "v": "кусок текста" }`
  - `{ "t": "done", "remaining": 7 }`
  - `{ "t": "error", "code": "limit" | "busy" | "closed" | "auth" | "bad_request" | "upstream", "message": "по-русски для пользователя" }`
- При `auth` (токен истёк) — клиент один раз молча получает новый токен через Turnstile и повторяет запрос.

## 5. Секции ниже
1. **«Бесплатно прямо сейчас»** — живой список топ-моделей из каталога (логика загрузки уже есть в `app.js`): аккуратные строки/карточки — имя, короткое описание, у кого бесплатно, «до …» для акций. Без эмодзи.
2. **«Как это работает»** — 3 шага в одну строку (Скачай → Выбери папку → Пиши задачу), каждый с маленькой анимированной иллюстрацией из HTML/CSS, а не иконкой.
3. **«Возможности»** — центрированный заголовок, под ним пилюли-вкладки («Агент в папке», «Диффы и разрешения», «Выбор модели», «Свои подписки»). Под ними горизонтальная лента карточек с выглядывающими соседями: в карточке слева текст (чип, заголовок, 2 строки описания), справа цветная панель со скриншотом приложения (`assets/app-*.png`, плюс возьми скриншоты из `../app/screenshots/` — скопируй нужные в `assets/`, сожми). Переключение вкладок и свайп/стрелки — плавная прокрутка ленты.
4. **«Открытый код»** — строка: MIT, ссылка на GitHub, «Каталог обновляется ботом каждые 30 минут», время последнего обновления каталога из `catalog.json`.
5. **FAQ** — аккордеон с плавным раскрытием (оставь текущие вопросы, добавь: «Что за демо-чат на сайте и что вы сохраняете?» → «Ничего: переписка живёт только в вкладке браузера и сгорает»).
6. Подвал: логотип, ссылки, © vsemkod contributors.

## 6. Анимации и производительность
- Появление секций при прокрутке (IntersectionObserver: `opacity` + `translateY(12px)`, 400–600 мс, лёгкий stagger). Ховеры кнопок и карточек — 150–200 мс.
- `prefers-reduced-motion: reduce` — отключить кривые, печать и появление (показывать сразу).
- Никаких внешних шрифтов и библиотек. Lighthouse: производительность и доступность ≥ 95 на десктопе. Картинки `loading="lazy"`, размеры заданы (нет сдвигов макета).
- Адаптив: 360px, 768px, 1280px, 1600px. На мобильных окно-демо упрощается (без боковой панели), чат остаётся рабочим.
