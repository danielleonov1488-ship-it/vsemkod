## Что это

**vsemkod** — открытое десктоп-приложение для вайбкодинга: выбираешь папку, пишешь задачу — агент сам читает проект, пишет код и запускает его.

- Только бесплатные топовые модели: Kimi, GLM, DeepSeek, Nemotron, Qwen и другие.
- Бот-каталог круглосуточно ищет новые бесплатные раздачи — они сами появляются в приложении.
- Каждый пользователь работает на своих бесплатных квотах: подключение провайдера в один клик, без подписок.
- Модель упёрлась в лимит — vsemkod сам переключится на другого провайдера или на следующую лучшую модель.
- Чаты и ключи хранятся только на твоём компьютере.
