# Этап D2 — живой ход агента, скорость, проекты (по отзыву владельца)

Владелец потестил собранное приложение: написал «жив?» с моделью Nemotron 3 Ultra (Kilo) — и видел только «Агент работает» без каких-либо признаков жизни. Диагностика: Kilo работает, но Nemotron 3 Ultra (550B, reasoning) на бесплатном тарифе отвечает 5–15 с даже на «ping», а с большим системным промптом агента — до минуты и дольше; из 2 запросов роутера 1 упал (вероятно 429: анонимный Kilo — 200 запросов/час на IP). Интерфейс при этом ничего не показывает. Ожидание владельца: «как в любом харнессе» (Codex, Claude Code).

## 1. Живой ход агента (главное)
- Пока агент работает — **лента хода в реальном времени**: строка «Думает…» с живым таймером и потоком рассуждений модели (свёрнутым до 2 строк, раскрывается), каждый вызов инструмента появляется сразу при старте (иконка + «Читает settings.tsx…», «Запускает npm test…» со спиннером → по завершении «Прочитал», «Запустил — 17 пройдено», дифф для правок). Текст ответа стримится по мере генерации.
- **После финального ответа ход сворачивается** в одну строку «Работал 1 мин 12 с · 6 действий ▸» (раскрывается обратно), а ответ остаётся на виду — как в Codex.
- Статус в шапке чата и в боковой панели у чата (точка-индикатор «работает» / «ждёт разрешения» / «ошибка»).
- Если **нет ни одного токена 20 с** — под лентой спокойная подсказка «Модель думает дольше обычного — бесплатные модели иногда отвечают до минуты · Сменить модель» (кнопка открывает меню моделей; смена модели применяется к следующему шагу/повтору). Через 120 с без токенов — понятная ошибка с кнопками «Повторить» и «Сменить модель».
- Ошибки роутера/провайдера (429, квота, 5xx, таймаут) доходят до UI человеческим текстом и тостом; при автовыборе — тост «Переключился на X — у Y кончилась квота» (событие роутера уже есть — проверь, что оно реально доходит).

## 2. Скорость и выбор модели по умолчанию
- Роутер: таймаут до первого байта для бесплатных провайдеров — 45 с (сейчас проверь, какой), затем фолбэк на следующего провайдера/модель; 429 от Kilo — охлаждение с учётом `Retry-After`.
- **Модель по умолчанию** для нового пользователя — быстрая и рабочая с инструментами из доступных без ключа. Замер 2026-11-25 (Kilo, короткий запрос, TTFB): `nemotron-3.5-lightning` ~1.0 с, `beam-free` ~1.2 с, `ernie-5.5-flash-preview` ~1.6 с, `glyph-cluster` ~1.8 с, `flint-v1.0` ~2.3 с, `nemotron-3-ultra` ~4.8 с, `nemotron-3.5-super` ~7.3 с; `ling-3.2-flash`, `particle-1` — 429; `dots-3-note-preview` — 404; `ampersand-v0.1` — 401. Выбирай по каталогу: среди моделей с `auth: none`, tools и активным предложением — предпочитай известные быстрые (держи небольшой список предпочтений в коде, легко менять), а не самую «умную».
- Роутер запоминает среднее время до первого байта по модели/провайдеру (в памяти + в `usage.json`, без содержимого) и показывает его в меню моделей мелкой подписью («~2 с»), чтобы человек видел, что быстро.

## 3. Проекты как в Codex / Claude Code
- В боковой панели — список **проектов (папок)** с кнопкой **«+»** («Добавить проект» → системный выбор папки), у каждого проекта — его чаты и «Новый чат в проекте». Выбранный проект подсвечен. В поле ввода чип папки — переключатель проекта (последние проекты + «Выбрать папку…»).
- Кнопка «+» в поле ввода — меню: «Прикрепить файлы или картинки», «Упомянуть файл (@)», «Команды (/)».

## 4. Изоляция движка от чужих настроек
- Сейчас встроенный OpenCode подхватывает `~/.claude/CLAUDE.md` и `~/.claude/skills`, `~/.agents/skills` пользователя (видно в логе движка). Это чужие инструкции другого приложения — **отключи** (штатные переменные/конфиг OpenCode, например `OPENCODE_DISABLE_CLAUDE_CODE*` — сверь с версией 2.4.1). Навыки vsemkod — только из своей папки в userData и из проекта.

## Проверка (обязательно)
- Юнит-тесты: сворачивание хода после ответа, таймер «нет токенов 20/120 с», выбор модели по умолчанию, учёт TTFB, обработка 429 → охлаждение → фолбэк.
- Живой прогон через Kilo: «жив?» на модели по умолчанию — ответ < 10 с, ход виден и сворачивается; задача с инструментами («создай hello.txt и прочитай его») — видны живые шаги; принудительно медленная/падающая модель (мок) — подсказка через 20 с, ошибка с «Повторить» через 120 с.
- Скриншоты в обеих темах (`app/screenshots/d2-*.png`): ход в процессе, свёрнутый ход, подсказка о медленной модели, проекты с «+», меню «+».
- `npm test`, `npm run typecheck`, `npm run build`. Обнови `app/README.md`.
