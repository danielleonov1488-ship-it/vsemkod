# Этап E — голосовой ввод (локально, бесплатно, почти все языки, долгая диктовка)

Продолжаем `app/` (этапы A–D2 применены). Нужен встроенный голосовой ввод, как диктовка в Claude Code / Codex: нажал микрофон — долго наговариваешь промпт — текст появляется в поле ввода, его можно поправить и отправить. Для проекта — **ноль затрат и ноль серверов**: распознавание **локально на компьютере пользователя**.

## Требования
- **Модель**: Whisper (≈99 языков, автоопределение языка, пунктуация). Распознавание полностью локальное, офлайн после загрузки модели. Никаких наших серверов.
- **Движок** — выбери после проверки актуального состояния (ноябрь 2026) и коротко обоснуй в отчёте:
  1. предпочтительно `whisper.cpp` (MIT) — готовые бинарники/аддон под Windows x64, macOS arm64/x64, Linux x64 (как бинарник движка OpenCode: `extraResources`, скачивание в `scripts/fetch-*.mjs` с проверкой sha256), с ускорением GPU (Metal/Vulkan), если доступно;
  2. либо `@huggingface/transformers` (ONNX Whisper в Web Worker, WebGPU с запасным WASM) — если whisper.cpp не даёт надёжных сборок под все три ОС без компиляции.
  Критерий: на обычном 8-ядерном CPU «Быструю» модель распознавать быстрее реального времени (RTF < 0.5), приложение не подвисает (распознавание вне UI-потока).
- **Модели** (скачиваются по первому нажатию микрофона, с явным согласием и размером): **«Точная» по умолчанию** (large-v3-turbo квантованная, ~500–800 МБ) и «Быстрая» (Whisper small/base мультиязычная, ~150–250 МБ) для слабых компьютеров.
- **Автопроверка железа** (решение владельца: по умолчанию точная, но не мучить слабые ПК): перед первой загрузкой — оперативная память < 8 ГБ или нет ускорения GPU и слабый CPU → предложить «Быструю» с пояснением; после загрузки «Точной» — короткий замер на встроенном 10-секундном образце: если медленнее 0.8× реального времени, показать «Точная модель на этом компьютере работает медленно — переключиться на Быструю?» (одна кнопка, выбор запоминается). Источник — официальные репозитории моделей на Hugging Face, проверка sha256, хранение в userData, прогресс загрузки, возможность удалить в настройках.
- **Долгая диктовка**: запись без ограничения длины; VAD (Silero или встроенный в движок) режет на фразы по паузам; каждая фраза распознаётся сразу и дописывается в поле ввода (живой промежуточный текст серым, финальный — обычным). Остановка — повторное нажатие, Esc или долгая тишина (настраивается: выкл/10 с/30 с).
- **UI** (в стиле приложения, без эмодзи): кнопка микрофона в поле ввода рядом с отправкой; во время записи — аккуратная живая «волна» уровня, таймер, кнопки «Стоп» и «Отмена». Горячая клавиша: удерживать `Ctrl+Space` — говорить (push-to-talk), отпустить — вставить; короткое нажатие — переключить запись. Текст вставляется в позицию курсора.
- **Настройки → Голос**: модель (Быстрая/Точная, загрузить/удалить, размер на диске), язык (Авто или выбранный), автостоп по тишине, микрофон (выбор устройства), «Облачное распознавание через мой ключ Groq» (только если Groq подключён; whisper-large-v3-turbo Groq; по умолчанию выкл) .
- **Приватность**: аудио нигде не сохраняется, только в памяти до распознавания. Разрешение на микрофон — системный запрос Electron (`setPermissionRequestHandler` только для `media` с audio, только для своего окна).
- **Веб-копия на сайте** (если уже есть `app/src/web/`): кнопка микрофона показывает «Голосовой ввод работает в приложении».

## Проверка (обязательно)
- Юнит-тесты: склейка фраз (промежуточный → финальный текст), вставка в позицию курсора, автостоп по тишине, проверка sha256 и докачка модели, отказ без согласия на загрузку.
- Живой прогон без микрофона: на тестовых WAV (сгенерируй синтезатором речи или возьми свободные записи, добавь в `tests/fixtures/`, коротко: русский, английский, ещё один язык, плюс длинный 2–3-минутный файл) — распознавание проходит, замерь RTF для обеих моделей и напиши цифры в отчёт.
- Скриншоты в обеих темах: кнопка микрофона, запись с волной, загрузка модели, раздел настроек «Голос».
- `npm test`, `npm run typecheck`, `npm run build`. Обнови `README.md` и `THIRD_PARTY_NOTICES.md` (лицензии движка и моделей).

## Ограничения
Только `app/`. Не коммить и не пушь. Если Windows не даёт писать в существующие файлы — отдай патч `app/stage-e.patch`.
