# Этап K6: только сильные бесплатные модели + новые источники

Решение владельца, 2026-11-27:
- в меню и автовыборе остаются только бесплатные модели **не слабее GPT-5** по Artificial Analysis;
- одно исключение — **Nemotron 3 Ultra** как запас без лимитов;
- **модели без цензуры не фильтруются** — у них своя вкладка, там остаются все;
- свои подписки и ключи не фильтруются;
- **GigaChat не берём**.

Плюс новые источники из `STAGE-K5-SOURCES.md` — **всё, кроме п. 3 (GigaChat)**. Прочитай тот файл: п. 0 (совместимость), 1, 2, 4, 5 и 6 выполняются в этом этапе.

Работаешь в `catalog-bot/**` и `app/**`. Не коммить и ничего не публикуй. Рабочие копии — только в `%TEMP%`.

## 1. Порог качества
**Уровень GPT-5 по AA.**
- В индексе v5 оценки у GPT-5 нет: модель устарела.
- По Progress Index v1 GPT-5 (high) = 270,7; тот же уровень у моделей с индексом v5 около 12. Nemotron 3 Ultra: Progress Index 270,6, v5 11,8.
- Поэтому порог: **индекс v5 ≥ 12**.

**Конфиг бота** (`catalog-bot/src/config.ts` или реестр):
- `qualityFloor: { indexVersion: "5", minIndex: 12, reference: "GPT-5 (high), AA Progress Index v1 = 270.7" }`.
- Если AA сменил версию индекса, а порога для неё нет, бот не прячет новое и не меняет прежние решения: оставляет уровни как были. Владельцу — уведомление в Telegram и строка в журнале: «AA сменил индекс на vN — обновите qualityFloor».

**Классы моделей каталога:**

| Класс | Условие | `tier` в каталоге |
|---|---|---|
| сильная | индекс ≥ 25 | `top` |
| хорошая | 12 ≤ индекс < 25 | `good` |
| запасная | в списке `fallbackModels` (сейчас `nemotron-3-ultra`) | `good` |
| ручное исключение | в списке `qualityOverrides` с причиной | по причине. Сейчас: `kimi-k2.7-code` → `good`, «нет индекса v5, Progress Index 287,6 > GPT-5» |
| без цензуры | название или id совпадает с шаблоном | без изменений (`new`), фильтр не применяется |
| слабая или без оценки | всё остальное | **`basic`** |

`basic` скрывается уже в приложении 0.1.5 (`modelOptions` отбрасывает `basic`), поэтому новых полей не нужно. Шаблон «без цензуры» — как в `app/src/shared/model-tags.ts`: `uncensor|abliterat|dealign|heretic|unfilter|unalign|no-?refusal`; вынеси общий.

**Сопоставление с AA** (улучши `matchCatalog`). AA называет модели с суффиксами: «GLM-5.3-Flash Max», «DeepSeek V4.1 Flash 1017 Max», «Qwen3.8 27B Xhigh», «Nemotron 3.5 Super VL». Нормализуй:
- убери уровень рассуждений: Max, Xhigh, High, Medium, Low, Minimal, Reasoning, Non-reasoning;
- убери даты (1017, 0813) и «VL»;
- сравнивай с нормализованными id и названиями каталога;
- из вариантов бери лучший индекс (как сейчас).

Тесты на эти примеры обязательны.

## 2. Приложение
- **Модели из списков провайдеров** (`origin: "discovered"`, id `x-…`): в меню **не показывать**, кроме моделей без цензуры. Их раздачи, слитые с каталожными моделями, продолжают работать как дополнительные источники сильных моделей.
- **Вкладка «Без цензуры»** показывает все модели без цензуры — каталожные любого `tier` и найденные в списках — с подключёнными и подключаемыми источниками. Фильтр качества на них не действует.
- **Автовыбор и модель по умолчанию** (`src/shared/catalog.ts`):
  - `quickModels` → `["ernie-5.5-flash-preview", "beam-free", "nemotron-3.5-super", "ling-3.2-flash"]` — только те, что есть без ключа;
  - убери `nemotron-3.5-lightning`, `glyph-cluster`, `flint-v1.0`;
  - дальше — сильные и хорошие модели по убыванию индекса AA (передай `benchmarks` в `automaticModels`; без данных — как сейчас по `rank`);
  - **`nemotron-3-ultra` всегда последним** — запас без лимитов;
  - `basic` и `discovered` в автовыбор не попадают, без цензуры — тоже.
- **Сохранённый выбор.** Чат или настройка ссылается на модель, которая стала `basic` (например, у пользователя выбрана Nemotron 3.5 Lightning): показываем и используем модель по умолчанию. Роутер по-прежнему принимает старый id, если его явно прислали: модель есть в каталоге, только скрыта.
- **Подпись в меню.** «Лучшие» и «Бесплатные» сортируются по индексу. Сделай короткую подсказку внизу вкладки «Бесплатные» (Claude поправит текст): «Показаны модели не слабее GPT-5 по рейтингу Artificial Analysis. Без цензуры — в своей вкладке».
