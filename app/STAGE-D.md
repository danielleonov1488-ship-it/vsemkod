# Этап D — базовые функции харнеса, светлая тема, полноценные настройки

Продолжаем `app/` (этапы A–C готовы, см. `app/README.md`). Цель — догнать по базовым функциям лучшие десктоп-харнессы (Claude Code desktop, DeepSeek Harness), оставаясь простыми. **Почти всё уже умеет встроенный OpenCode 2.4.1** (в SDK есть `agent`, `session.revert`, `command`, `skill`, `mcp`, `pty`, `file`, `usage`, `form`, `config`, `vcs/branch`, события `session.usage`, `session.compaction`, `permission.asked`, `todo` и т.д.) — сначала изучи SDK (`node_modules/@opencode/client`) и делай через адаптер `src/main/engine/adapter.ts`, а не изобретай своё.

Дизайн — строго в стиле `app/design/*` (графит + мятный, спокойно, плотно, без эмодзи и «нейрослопа»). Весь UI на русском. **Код не раздувать**: переиспользуй компоненты, без новых UI-библиотек (исключение — `@xterm/xterm` для терминала, если нужен). Каждая новая функция — минимальная, но доведённая до конца.

## 1. Темы и внешний вид
- Тёмная / Светлая / Как в системе (по умолчанию — как в системе). Светлая палитра — тёплая, как на сайте: фон `#F5F4F0`, поверхность `#FFFFFF`, линия `#E4E1DA`, текст `#141617`, вторичный `#5E6461`, акцент для текста/кнопок `#0F8F5A`, мятный `#3DDC97` — для мелких акцентов. Все цвета — через переменные `design/free-ai.css` (добавь `[data-theme="light"]`), без хардкода в компонентах. Заголовок окна и `nativeTheme` синхронизированы.
- Размер шрифта интерфейса: Мелкий / Обычный / Крупный. Шрифт кода — моно.

## 2. Поле ввода
- **Режим доступа** — чип в поле ввода (цикл по Shift+Tab): «Только чтение» (агент `plan` движка — ничего не меняет), «Спрашивать» (по умолчанию: разрешение на правки и команды), «Авто-правки» (правки файлов в папке без вопросов, команды — с вопросом), «Полный доступ» (без вопросов; при первом включении — диалог-предупреждение). Реализуй через штатные агенты/правила разрешений движка на уровне сессии.
- **План**: в режиме «Только чтение» агент пишет план; под ним карточка «Выполнить план» → переключает на «Спрашивать»/«Авто-правки» и отправляет «Выполни план».
- **Вложения**: картинки (вставка из буфера, перетаскивание, кнопка-скрепка) и файлы; превью-чипы с удалением. Картинки — только если модель поддерживает изображения (по данным движка/каталога), иначе понятная подсказка.
- **@-упоминания** файлов и папок проекта (поиск через движок, стрелки/Enter/Tab), **/команды**: `/new`, `/compact`, `/plan`, `/model`, `/export` (чат в markdown-файл), плюс пользовательские команды и навыки (skills) движка. Всплывающий список в стиле меню моделей.
- **Пока агент работает**: Enter ставит сообщение в очередь (видна, можно удалить), Ctrl+Enter — «вмешаться» (прервать и отправить сразу). Esc дважды — стоп.
- **Уровень рассуждений** (если у модели есть варианты reasoning в движке): маленький селектор рядом с моделью.
- **Индикатор контекста**: кружок с процентом заполнения окна модели (из `session.usage`), по наведению — токены и разбивка; автосжатие контекста движком включено, событие `session.compaction` показывать строкой «Контекст сжат».

## 3. Сообщения и ход работы
- У сообщения пользователя: «Копировать», «Изменить и отправить заново» (для последнего), **«Откатить сюда»** (`session.revert`: возвращает файлы и историю к этому моменту, с подтверждением; «Вернуть» через unrevert, если есть).
- У ответа: «Копировать», «Повторить».
- **Список задач агента** (todo движка) — компактная закреплённая карточка над полем ввода, сворачиваемая.
- **Вопросы агента** (form/question движка) — инлайн-карточка с вариантами и полем «Свой ответ».
- Блоки рассуждений модели — свёрнуты по умолчанию («Думал 12 с»).

## 4. Боковая панель и чаты
- Чаты сгруппированы по папкам проектов (заголовок группы — имя папки, сворачивается; «Новый чат в этой папке»). Поиск по названиям (Ctrl+K).
- Контекстное меню чата: Переименовать, Закрепить, Форк (`session.fork`), Архивировать, Удалить (с подтверждением). Закреплённые — сверху. Раздел «Архив» в настройках/внизу списка.

## 5. Правая панель (Ctrl+B)
Вкладки:
- **Изменения** — все файлы, изменённые в чате (+/−), раскрываемый дифф, «Отменить изменения файла».
- **Файлы** — дерево папки проекта и просмотр файла (только чтение, моно, без тяжёлой подсветки).
- **Терминал** (Ctrl+J) — терминал в папке проекта через `pty` движка; команды агента видны в нём или отдельной вкладкой.
Ширина панели перетаскивается и запоминается.

## 6. Настройки — разделы (левое меню внутри страницы настроек)
1. **Общие**: тема, размер шрифта, папка по умолчанию, режим доступа по умолчанию, поведение Enter во время работы агента (очередь / вмешаться), уведомления (системное уведомление, когда агент закончил или ждёт разрешения и окно не в фокусе; звук вкл/выкл), «Не давать компьютеру уснуть, пока агент работает» (`powerSaveBlocker`), обновления (проверить, текущая версия).
2. **Модели и подключения**: то, что уже есть (провайдеры, подписки, ключи, автовыбор, буфер обмена, обновление каталога) + у «Своего OpenAI-совместимого» — кнопка «Загрузить список моделей» с чекбоксами и полями контекст/макс. вывод.
3. **Агент**: «Правила для всех проектов» — редактор глобального файла инструкций движка (AGENTS.md в конфиге движка), подсказка, что в проекте можно положить свой `AGENTS.md`; веб-поиск вкл/выкл (если движок поддерживает без внешних ключей); макс. шагов агента (если есть в конфиге движка).
4. **MCP-серверы**: список (статус: подключён/ошибка/выключен), добавить локальный (команда + аргументы + env) или удалённый (URL + заголовки), вкл/выкл, удалить, «Проверить». Через MCP-API/конфиг движка.
5. **Навыки**: список навыков движка (имя, описание, откуда), «Открыть папку навыков».
6. **Горячие клавиши**: список всех сочетаний (Ctrl+N новый чат, Ctrl+K поиск, Ctrl+B панель, Ctrl+J терминал, Ctrl+, настройки, Shift+Tab режим доступа, Esc Esc стоп, Ctrl+Enter вмешаться). Переназначение не нужно.
7. **Данные**: «Открыть папку данных», «Открыть логи», «Экспортировать все чаты» (markdown в выбранную папку), «Очистить кэш каталога». Строка «Телеметрии нет: vsemkod ничего не отправляет, кроме запросов к выбранным вами моделям».
8. **О программе**: версия, лицензия MIT, GitHub, vsemkod.ru.
Все настройки сохраняются (расширь `Preferences` и storage), применяются сразу.
